# ROOT OS - Emojis animes

5 GIF transparents, 128 x 128 pixels, boucles de 1,92 seconde.

- root_alerte : pulsation du triangle ambre.
- root_terminal : curseur turquoise clignotant.
- root_recolter : fleche qui descend vers le bac.
- root_scan : balayage turquoise dans la loupe.
- root_retour : fleche qui se deplace vers la gauche.

Importer les cinq fichiers root_*.gif comme emojis dans Discord.
apercu.gif est une planche de presentation, pas un emoji a importer.
Les identifiants Discord sont attribues apres import ; aucun import ni
changement du bot n'a ete effectue.

Adaptations animees des pictogrammes Lucide 0.468.0 du pack PNG existant.
Conserver LICENSE-LUCIDE.txt lors du partage.
Le script reproductible est disponible dans ../build_animated_emojis.cjs.
