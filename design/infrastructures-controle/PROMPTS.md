# ROOT OS - Infrastructures de controle

Six illustrations generees avec l'outil ImageGen integre. Aucune modification du bot.
Format panoramique proche de 3:1. Les fichiers originaux sont conserves sans recadrage.

Niveaux 0, 1 et 2 : meme piece, meme fenetre, meme lampe rouge ; renovation progressive.
Niveau 3 : nouveau local technique avec une seule baie.
Niveau 4 : salle des serveurs.
Niveau 5 : immense datacenter vu depuis le poste de supervision.
La lampe rouge assure la continuite entre les six niveaux.
